## Quest・LEVEL CHECKの共通基準

全分野・全LEVELに適用します。

- Questの✓は、その項目で確認できた理解を示します。用語や選択肢の正解から、別の環境での理解・操作まで推定しません。
- LEVEL CHECKでは、状況・目的を理解し、使う操作を選び、適切な場所で実行し、結果を判断・説明できるかを確認します。コマンドを入力できたことだけでは合格にしません。
- 確認する前に、環境、機器・接続先、画面、現在の場所やモード、設定済み事項、作業目的・相手を共有します。実際の構成と仮想例を区別します。
- 理解と操作は別々に記録し、どの条件なら自力でできるか、どこから支援が必要かを残します。環境が変わったときの再現は、確認するまで未確認です。
- つまずきは、状況・用語・目的・操作の選択・場所やモード・事前設定・実行・結果判断に分けて確かめます。設定不足による不通を理解不足と決めつけません。
- 詳細な現在地と根拠はCBで管理し、KCのQuest欄は項目名とチェックのみとします。
