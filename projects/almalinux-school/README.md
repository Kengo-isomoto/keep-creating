# 🏫 AlmaLinux｜学校実習

職業訓練校のAlmaLinux環境で、Linuxサーバーの基本操作から、ユーザー管理・アクセス制御・ネットワーク調査・運用の自動化まで学習しています。

手順書・ノートを参照し、必要に応じてヒントや説明を受けながら実習しています。コマンドを実行するだけでなく、出力を読んで目的を達成できたか確認することを大切にしています。

最終更新：2026年11月2日

## 📁 ファイル・ディレクトリの操作

| 目的 | 使用したコマンド・機能 | 実習で確認したこと |
| --- | --- | --- |
| 現在地と内容の確認 | `pwd`、`ls`、`cd` | 現在の場所と対象のパスを確認 |
| ディレクトリの作成 | `mkdir` | 指定した親子関係で作成し、一覧で確認 |
| 詳細情報の確認 | `ls -l`、`ls -ld` | 所有者・グループ・権限を確認。ディレクトリ自体と中身の表示を区別 |
| テキスト作成・表示 | `echo`、`>`、`>>`、`cat` | 出力先を指定して保存し、内容を確認 |
| ファイル形式の確認 | `file` | 設定ファイルがテキストであることを確認して表示 |
| inodeなどの確認 | `stat`、`ls -i` | 同じinode番号、アクセス権限、所有者、日時を確認 |

相対パス・絶対パス、ユーザー名と同名ディレクトリの違い、上書きと追記を実際の操作と結びつけて学習しました。

## 📦 バックアップ・クリーニング・復元

ホームディレクトリ配下を整理する想定で、削除前のバックアップから復元まで取り組みました。今回の対象は隠しファイルを除くホーム配下の項目です。

| 段階 | 操作 | 結果・確認 |
| --- | --- | --- |
| 作成 | `tar -cvf` | ファイル・ディレクトリをアーカイブに保存 |
| 内容確認 | `tar -tvf` | 保存されたファイル・下位ディレクトリ・リンクの一覧を確認 |
| 圧縮 | `gzip` | 圧縮後のファイルの存在・サイズと格納内容を確認 |
| クリーニング | `rm -r` | 対象を削除し、バックアップが削除対象外に残ることを確認 |
| 復元 | `tar -xvf` | 元の場所への展開を実施（成功は本人報告） |

読み取り権限による作成エラーを確認し、必要な権限で作り直しました。削除時の確認では、Enterと明示的な承認による動作の違いも経験しました。

圧縮前後のサイズを比較し、圧縮したファイルが必ず大きく縮むわけではないことも学習しました。

## 👥 ユーザー・グループ管理

新しい部署と社員2名を用意する想定で、既存の実習対象と区別するため名前に `2` を付けて実施しました。

| 操作 | 使用したコマンド | 結果の確認 |
| --- | --- | --- |
| 部署グループ作成 | `groupadd` | `getent group` で登録を確認 |
| ユーザー2名の作成 | `useradd` | `id` でUID・主グループを確認 |
| 部署への追加所属 | `usermod -aG` | 元の主グループを維持し、追加所属を確認 |
| パスワード設定 | `passwd` | 対話入力後の更新成功表示を確認 |

UIDはユーザーの識別番号、GIDはグループの識別番号として読み取り、主グループと追加所属を区別しました。

## 🔐 所有者・権限設定とアクセス検証

個人用ディレクトリと部署共有ディレクトリを作り、用途に合わせて所有者・所有グループ・パーミッションを設定しました。

| 対象 | 所有者 | 所有グループ | 権限 |
| --- | --- | --- | --- |
| 個人用：codeninja2 | codeninja2 | root | `700 / drwx------` |
| 個人用：datadiva2 | datadiva2 | root | `700 / drwx------` |
| 部署共有：Share | root | dreamteam2 | `770 / drwxrwx---` |

使用したコマンド：`chown`、`chgrp`、`chmod`、`ls -ld`

設定後は表示確認に加えて、実際のユーザー権限で検証しました。

- codeninja2として個人用ディレクトリにテキストを作成し、内容を表示。
- datadiva2として同じファイルを読み取ろうとすると、権限不足で拒否。
- 個人用ディレクトリへの移動も拒否されることを確認。

共有ディレクトリは所有者・グループ・権限の設定まで確認しました。

## 🌐 ネットワーク設定の調査

前任者のドキュメントがない想定で、接続済みのサーバーから設定情報を調査しました。

| 調査項目 | 使用したコマンド・確認先 | 確認した内容 |
| --- | --- | --- |
| IP・サブネットマスク | `ip addr` | 各接続口のIPv4とプレフィックス |
| デフォルトゲートウェイ | `ip route` | 転送先、接続口、経路のmetric |
| DNSサーバー | `file /etc/resolv.conf`、`cat /etc/resolv.conf` | nameserverの設定 |
| IPv4の取得方法 | `nmcli connection show` | 接続設定のauto/manualとDHCP情報 |
| 必要な行の抽出 | パイプと`grep` | 設定表示から対象項目を絞り込み |
| 外部への疎通 | `ping` | 10送信・10受信、損失0%を確認 |

2つの接続口について、自動取得と手動設定の違いを確認しました。同じ宛先条件のデフォルト経路では、小さいmetricが優先されることも出力と結びつけて整理しました。

## ⚙️ システム・サービス管理

`sshd` の状態確認・停止・起動と、自動起動設定の変更を実施しました。

| 操作 | 使用したコマンド | 確認した変化 |
| --- | --- | --- |
| 状態確認・停止・起動 | `systemctl status / stop / start sshd` | 停止後はinactive、起動後はactive |
| 自動起動の無効化・有効化 | `systemctl disable / enable sshd` | disabledとenabledの変化 |
| firewalldの再起動 | `systemctl restart firewalld` | 再起動後の稼働状態と開始時刻 |

自動起動については、`multi-user.target.wants` 配下のsshdへのシンボリックリンクが削除・再作成されることも確認しました。

systemd・Unit・service・targetとLinuxの起動の流れも学習しています。

## 💾 ストレージ・ファイルシステム

MBR/GPT、パーティション、XFS、マウント、LVMの仕組みを学習し、実際の構成と空き容量を確認しました。

| 確認内容 | 使用したコマンド | 実習内容 |
| --- | --- | --- |
| ディスク構成 | `lsblk` | 接続されたストレージ構成の確認 |
| 使用量・空き容量 | `df -h` | 追加保存に必要な容量が足りるか判断 |
| LVM構成 | `pvdisplay`、`vgdisplay`、`lvdisplay` | PV → VG → LVのつながりを確認 |

ルート領域の空き容量とVGの空きを調べ、想定したデータ移行には容量が不足することを判断しました。

## 🔎 ログ管理・ファイル検索

- rsyslogの設定、facility・priority、ログの出力先を学習。
- `logger` を使ってメッセージを送信。
- `grep` でログから文字列を抽出し、検索語によって一致する行が変わることを確認。
- `find` で場所・種類・名前・サイズを指定し、`-exec` で検索結果へ処理を実行。
- `/dev/null` を利用し、ファイルを残したまま内容を空にする操作を確認。

使用例：`find` の `-type f`、`-name`、`-size 0c`、`-exec ls -l`

ログローテーションの仕組みと設定項目も学習しました。個別設定からローテーション実行・結果確認までは、今後の実習対象です。

## 🕒 時刻管理

`chronyc activity`、`chronyc sources`、`chronyc makestep` を実行しました。

時刻ソースのオンライン状態、同期に使用中のソースを確認し、時刻補正の応答を確認しました。出力を見て状態を判断する練習は継続します。

## 📝 Vimによる編集・検索結果の保存

元ファイルをホームへコピーし、練習用ファイルで編集・保存・表示確認を行いました。

| 内容 | 使用した操作 | 確認したこと |
| --- | --- | --- |
| モード切り替え | `i`、`Esc` | 挿入からコマンドモードへ戻って編集 |
| 行削除・元に戻す | `dd`、Undo操作 | 行削除と変更を戻す操作を実施 |
| 置換 | Vimの置換コマンド | 文字列・文字の一括置換を実施し、変更を戻す操作も経験 |
| 範囲の削除 | 行番号を確認して削除 | 21行目以降を削除し、保存後に20行を確認 |
| 保存・終了 | `:wq`、`cat` | 保存した内容をシェルから再確認 |
| 条件に合う行の抽出 | `grep`、パイプ、`>` | 大文字Lで始まる行を別ファイルに保存し、2行の抽出結果を確認 |

実際に入力する文字、引用符、行頭を指定する検索条件、パイプと保存先指定の役割を、課題の中で整理しました。
