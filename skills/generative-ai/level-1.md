# 🤖 Generative AI
## LEVEL 1｜安全な基本利用

### LEVEL CHECK

本人が、入力してよい情報を判断し、生成AIの出力をそのまま正解とせず確認して利用できることを確認します。

### Quest

Questの✓は、目的・方法・結果の意味について理解を確認したことを表します。実際に操作し、結果を判断・説明できるかはLEVEL CHECKで確認します。

- [x] 生成AIに入力してよい情報を判断する基準が分かる
- [ ] 目的が伝わる依頼に必要な情報が分かる
- [ ] 生成AIの出力を確認する理由と観点が分かる
- [ ] 信頼できる資料と照合する方法が分かる
- [ ] 出力を採用・修正・保留する判断基準が分かる
