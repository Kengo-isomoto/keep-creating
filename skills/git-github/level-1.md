# 🌱 Git / GitHub
## LEVEL 1｜変更・共有の基礎

### LEVEL CHECK

本人が、変更内容を確認して適切な単位で記録し、GitHubへ共有できることを確認します。

### Quest

Questの✓は、目的・方法・結果の意味について理解を確認したことを表します。実際に操作し、結果を判断・説明できるかはLEVEL CHECKで確認します。

- [ ] Repositoryと作業場所の関係が分かる
- [x] Diffで何を確認するか分かる
- [x] Commitする変更の選び方が分かる
- [x] Commitの役割と内容が伝わるメッセージの付け方が分かる
- [ ] Pushの役割とGitHub上で反映を確認する方法が分かる
