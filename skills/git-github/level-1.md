# 🌱 Git / GitHub
## LEVEL 1｜変更・共有の基礎

### LEVEL CHECK

本人が、変更内容を確認して適切な単位で記録し、GitHubへ共有できることを確認します。

### Quest

- [ ] Repositoryと作業場所を確認する
- [ ] ファイルを変更し、Diffで変更内容を確認する
- [ ] Commitする変更を選択する
- [ ] 内容が分かるCommitを作成する
- [ ] PushしてGitHub上の反映を確認する
