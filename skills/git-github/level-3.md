# 🌱 Git / GitHub
## LEVEL 3｜競合・取り消しへの対応

### LEVEL CHECK

本人が、変更の競合や操作ミスが発生したときに状況を確認し、安全な方法を選んで対応できることを確認します。

### Quest

- [ ] 変更履歴と現在の状態を確認する
- [ ] 競合が発生した箇所と原因を確認する
- [ ] 必要な内容を判断して競合を解消する
- [ ] 誤った変更を安全な方法で取り消す
- [ ] 対応後の状態を確認し、変更内容を説明する
