# 🐧 Linux / Server
## LEVEL 1｜安全な基本操作

### LEVEL CHECK

本人が、Linux上で現在地と対象を確認しながら基本操作を安全に行い、実行結果を確認・説明できることを確認します。

### Quest

Questの✓は、目的・方法・結果の意味について理解を確認したことを表します。実際に操作し、結果を判断・説明できるかはLEVEL CHECKで確認します。

- [x] `pwd`の目的と現在地の読み方が分かる
- [x] `ls` / `ls -l`の目的と表示内容が分かる
- [x] `cd`による移動方法が分かる
- [x] 絶対パス・相対パスの違いと使い分けが分かる
- [x] `.` / `..` / `~`の意味が分かる
- [x] `mkdir` / `touch`の目的と使い方が分かる
- [x] `cp` / `mv`の目的と使い分けが分かる
- [x] `rm`の働きと削除前の確認事項が分かる
- [x] `cat`などでテキスト内容を確認する方法が分かる
- [x] `grep`で情報を絞り込む方法が分かる
- [x] `*` / `?`のワイルドカードの意味が分かる
- [x] TAB補完の働きが分かる
- [x] `>`と`>>`の違いと出力先の指定方法が分かる
- [x] `r / w / x`の意味が分かる
- [x] 所有者・所有グループ・その他の権限を`ls -l`から読み取れる
