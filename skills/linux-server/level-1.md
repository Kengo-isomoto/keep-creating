# 🐧 Linux / Server
## LEVEL 1｜安全な基本操作

### LEVEL CHECK

本人が、Linux上で現在地と対象を確認しながら基本操作を安全に行い、実行結果を確認・説明できることを確認します。

### Quest

- [x] `pwd`で現在地を確認できる
- [x] `ls` / `ls -l`でファイル・ディレクトリと詳細を確認できる
- [x] `cd`で目的のディレクトリへ移動できる
- [x] 絶対パス・相対パスを使い分けて移動できる
- [x] `.` / `..` / `~`の意味を理解して移動に使える
- [x] `mkdir` / `touch`でディレクトリ・ファイルを作成できる
- [x] `cp` / `mv`でコピー・移動・名前変更ができる
- [x] `rm`を使う前に削除対象を確認し、安全に削除できる
- [x] `cat`などでテキストファイルの内容を確認できる
- [x] `grep`で必要な情報を絞り込める
- [x] `*` / `?`のワイルドカードを用途に合わせて使える
- [x] TAB補完を使って入力ミスを減らせる
- [x] `>`と`>>`の違いを説明し、出力先をファイルへ変更できる
- [x] `r / w / x`の意味を説明できる
- [x] 所有者・所有グループ・その他の権限を`ls -l`から読み取れる
- [x] 755 / 700 / 644などの数字表記を`rwx`へ読み替えられる
- [x] 指定された権限を`chmod`で設定できる
- [x] 所有者・所有グループを確認し、必要に応じて`chown` / `chgrp`を使える
- [x] 通常権限で実行できない理由を考え、`sudo`が必要か判断できる
- [x] 実行後に結果を確認し、エラーなら内容を読んで報告できる
