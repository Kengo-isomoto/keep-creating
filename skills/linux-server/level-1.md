# 🐧 Linux / Server
## LEVEL 1｜安全な基本操作

### LEVEL CHECK

本人が、Linux上で現在地と対象を確認しながら基本操作を安全に行い、実行結果を確認・説明できることを確認します。

### Quest

- [ ] `pwd`で現在地を確認できる
- [ ] `ls` / `ls -l`でファイル・ディレクトリと詳細を確認できる
- [ ] `cd`で目的のディレクトリへ移動できる
- [ ] 絶対パス・相対パスを使い分けて移動できる
- [ ] `.` / `..` / `~`の意味を理解して移動に使える
- [ ] `mkdir` / `touch`でディレクトリ・ファイルを作成できる
- [ ] `cp` / `mv`でコピー・移動・名前変更ができる
- [ ] `rm`を使う前に削除対象を確認し、安全に削除できる
- [ ] `cat`などでテキストファイルの内容を確認できる
- [ ] `grep`で必要な情報を絞り込める
- [ ] `*` / `?`のワイルドカードを用途に合わせて使える
- [ ] TAB補完を使って入力ミスを減らせる
- [ ] `>`と`>>`の違いを説明し、出力先をファイルへ変更できる
- [ ] `r / w / x`の意味を説明できる
- [ ] 所有者・所有グループ・その他の権限を`ls -l`から読み取れる
- [ ] 755 / 700 / 644などの数字表記を`rwx`へ読み替えられる
- [ ] 指定された権限を`chmod`で設定できる
- [ ] 所有者・所有グループを確認し、必要に応じて`chown` / `chgrp`を使える
- [ ] 通常権限で実行できない理由を考え、`sudo`が必要か判断できる
- [ ] 実行後に結果を確認し、エラーなら内容を読んで報告できる
