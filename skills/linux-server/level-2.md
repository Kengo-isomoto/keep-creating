# 🐧 Linux / Server
## LEVEL 2｜手順に沿う定常運用

### LEVEL CHECK

本人が、手順を確認しながらサーバーの日常的な管理・確認作業を安全に実施し、結果を確認・記録・報告できることを確認します。

### Quest

- [ ] `useradd`でユーザーを作成できる
- [ ] `passwd`でユーザーへパスワードを設定できる
- [ ] `groupadd`でグループを作成できる
- [ ] `usermod -aG`でユーザーをグループへ追加できる
- [ ] `id`でUID・GID・所属グループを確認できる
- [ ] ユーザー・グループ・パーミッションを組み合わせてアクセス範囲を設定できる
- [ ] 別ユーザーからアクセスして、設定した権限が実際に効いているか確認できる
- [ ] `ps`でプロセスを確認できる
- [ ] `top`でCPU・メモリ・プロセスの状態を確認できる
- [ ] `ps -ef | grep ～`などで対象プロセスを絞り込める
- [ ] PID / PPIDの意味を説明し、プロセスの関係を確認できる
- [ ] `kill`を使う前に対象PIDを確認してプロセスを終了できる
- [ ] フォアグラウンド / バックグラウンドの違いを説明できる
- [ ] `&`や`Ctrl+C`が何をするものか判断して使える
- [ ] `systemctl status`でサービス状態を確認できる
- [ ] 許可された範囲でサービスの開始・停止・再起動を行い、結果を再確認できる
- [ ] `df`でディスク使用状況を確認できる
- [ ] ログから必要な情報を探せる
- [ ] パッケージの更新・インストールを、実行前に内容を確認して行える
- [ ] `tar`でアーカイブを作成・確認・展開できる
- [ ] `gzip` / `gunzip`で圧縮・解凍できる
- [ ] バックアップ → 削除 → 復元の一連の作業を手順に沿って行える
- [ ] 実施したコマンド・結果・エラーを記録して説明できる
