# 🐧 Linux / Server
## LEVEL 2｜手順に沿う定常運用

### LEVEL CHECK

本人が、手順を確認しながらサーバーの日常的な管理・確認作業を安全に実施し、結果を確認・記録・報告できることを確認します。

### Quest

Questの✓は、目的・方法・結果の意味について理解を確認したことを表します。実際に操作し、結果を判断・説明できるかはLEVEL CHECKで確認します。

- [ ] `useradd`によるユーザー作成の方法が分かる
- [ ] `passwd`によるパスワード設定の方法が分かる
- [ ] `groupadd`によるグループ作成の方法が分かる
- [ ] `usermod -aG`の意味と使用上の注意が分かる
- [ ] `id`の出力からUID・GID・所属グループを読み取れる
- [x] ユーザー・グループ・パーミッションによるアクセス制御の仕組みが分かる
- [ ] 別ユーザーで権限を確かめる目的と確認方法が分かる
- [ ] `ps`の目的とプロセス表示の読み方が分かる
- [x] `top`によるCPU・メモリ・プロセスの状態の見方が分かる
- [ ] `ps -ef | grep ～`による絞り込みの意味が分かる
- [ ] PID / PPIDの意味とプロセスの関係が分かる
- [ ] `kill`の働きと実行前に対象PIDを確認する理由が分かる
- [ ] フォアグラウンド / バックグラウンドの違いが分かる
- [ ] `&`や`Ctrl+C`の働きが分かる
- [x] `systemctl status`によるサービス状態の見方が分かる
- [x] サービスの開始・停止・再起動の違いと実行前後の確認事項が分かる
- [x] `df`によるディスク使用状況の見方が分かる
- [ ] ログから必要な情報を探す観点と方法が分かる
- [x] パッケージ更新・インストールの目的と実行前の確認事項が分かる
- [ ] `tar`によるアーカイブの作成・確認・展開の方法が分かる
- [x] `gzip` / `gunzip`による圧縮・解凍の違いが分かる
- [x] バックアップ・削除・復元の順序と確認事項が分かる
- [ ] 実施コマンド・結果・エラーを記録する目的と報告内容が分かる
