# 🐧 Linux / Server
## LEVEL 3｜一次切り分け・報告

### LEVEL CHECK

本人が、異常時に自分で確認順序を考えて一次切り分けを行い、確認済み事項・未確認事項・対応結果を整理して報告できることを確認します。

### Quest

- [ ] 障害内容を聞いて、まず何を確認するか考えられる
- [ ] 正常時と異常時の違いを整理できる
- [ ] `systemctl`でサービス状態を確認できる
- [ ] `ps` / `top`でプロセス・リソースの状態を確認できる
- [ ] `df`でディスク容量不足の可能性を確認できる
- [ ] ログからエラーや異常発生時刻を探せる
- [ ] IPアドレスなどネットワーク側の状態も確認候補に入れられる
- [ ] 一つの確認結果だけで原因を決めつけず、次の確認へ進める
- [ ] 「ここは正常だった」という結果も切り分け材料として扱える
- [ ] 原因候補を複数挙げて、確認する順番を考えられる
- [ ] 原因を特定できた場合、勝手に変更せず対応可能範囲を判断できる
- [ ] 対応後に同じ確認を行い、復旧したか再確認できる
- [ ] 分からない場合に、確認済み事項と未確認事項を整理して質問・報告できる
- [ ] 「症状 → 確認 → 原因候補 → 対応 → 再確認」を自分の言葉で説明できる
