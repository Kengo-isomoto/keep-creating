# 🌐 Network
## LEVEL 1｜接続・基本情報の確認

### LEVEL CHECK

本人が、ネットワークの基本情報を理解して確認し、通信結果から次に確認すべき場所を考えて説明・報告できることを確認します。

### Quest

- [ ] IPアドレスが何のためにあるか説明できる
- [ ] IPv4アドレスの基本構造を説明できる
- [ ] サブネットマスク / プレフィックスが何を分けているか説明できる
- [ ] 同一ネットワークか別ネットワークかを基本的な例で判断できる
- [ ] デフォルトゲートウェイの役割を説明できる
- [ ] DNSの役割を説明できる
- [ ] DHCPの役割を説明できる
- [ ] MACアドレスの役割を説明できる
- [ ] ARPがIPアドレスとMACアドレスをつなぐ仕組みだと説明できる
- [ ] TCP / UDPの基本的な違いを説明できる
- [ ] HTTP / HTTPS / SSH / DNSなど主要サービスとポートを確認できる
- [ ] `ip addr`で自分のIPアドレスを確認できる
- [ ] `ping`で指定先への疎通を確認できる
- [ ] 名前解決を確認できる
- [ ] 「IPでは届くが名前では届かない」など、結果から次に疑う場所を考えられる
- [ ] 確認した通信結果を自分の言葉で説明できる
