# 🌐 Network
## LEVEL 1｜接続・基本情報の確認

### LEVEL CHECK

本人が、接続先やネットワークの基本情報を確認し、通信結果を説明・報告できることを確認します。

### Quest

- [ ] 接続の構成と通信相手を確認する
- [ ] IPアドレス・プレフィックス・経路を確認する
- [ ] 指定先への疎通を確認する
- [ ] 名前解決とサービスへの接続を確認する
- [ ] 確認結果と未確認事項を整理・報告する
