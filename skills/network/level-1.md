# 🌐 Network
## LEVEL 1｜接続・基本情報の確認

### LEVEL CHECK

本人が、使用する機器・画面・通信先を把握した上で、自分のIPアドレス、指定先へのping、名前解決を実際に確認し、結果と次に確認する場所を自分の言葉で説明・報告できることを確認します。

### Quest

Questの✓は、目的・方法・結果の意味について理解を確認したことを表します。実際に操作し、結果を判断・説明できるかはLEVEL CHECKで確認します。

- [x] IPアドレスが何のためにあるか説明できる
- [x] IPv4アドレスの基本構造を説明できる
- [x] サブネットマスク / プレフィックスが何を分けているか説明できる
- [x] 同一ネットワークか別ネットワークかを基本的な例で判断できる
- [x] デフォルトゲートウェイの役割を説明できる
- [x] DNSの役割を説明できる
- [x] DHCPの役割を説明できる
- [x] MACアドレスの役割を説明できる
- [x] ARPがIPアドレスとMACアドレスをつなぐ仕組みだと説明できる
- [x] TCP / UDPの基本的な違いを説明できる
- [x] HTTP / HTTPS / SSH / DNSの標準ポートが分かる
- [x] `ip addr`の目的と、出力のどこが自分のIPアドレスか分かる
- [x] `ping`の送信・応答・損失の結果を読み取れる
- [x] 名前に対応するIPが返った結果を読み取れる
- [x] 「IPでは届くが名前では届かない」など、結果から次に疑う場所を考えられる
- [x] 通信結果から分かることと、まだ分からないことを区別できる
