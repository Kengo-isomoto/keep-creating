# 🌐 Network
## LEVEL 2｜手順に沿う点検・設定

### LEVEL CHECK

本人が、手順に沿ってネットワークの状態を点検し、基本的な設定・通信確認・前後比較・報告ができることを確認します。

### Quest

- [ ] スイッチの基本的な役割を説明できる
- [ ] ルーターの基本的な役割を説明できる
- [ ] VLANを使う目的を説明できる
- [ ] VLANによってネットワークを論理的に分割する考え方を説明できる
- [ ] ルーティングが必要になる場面を説明できる
- [ ] ルーティングテーブルの基本的な見方を理解する
- [ ] Cisco機器へ接続し、基本情報を確認できる
- [ ] 手順に沿って基本設定を行える
- [ ] 設定前と設定後を比較できる
- [ ] IPアドレス・サブネット・GWを指定された条件から設定できる
- [ ] 同一ネットワーク内の通信を確認できる
- [ ] 異なるネットワーク間の通信を確認できる
- [ ] VLANなどで意図した通信分離を確認できる
- [ ] 設定した内容と通信確認結果を記録できる
- [ ] 失敗した場合、設定と通信結果を確認して報告できる
