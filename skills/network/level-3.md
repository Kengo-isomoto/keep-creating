# 🌐 Network
## LEVEL 3｜一次切り分け・報告

### LEVEL CHECK

本人が、通信障害の症状と影響範囲を整理し、確認結果を使って原因候補を一つずつ切り分け、対応または引き継ぎを判断・報告できることを確認します。

### Quest

- [ ] 「誰が・どこへ・いつから・どのようにつながらないか」を整理できる
- [ ] 自分だけか複数人かなど影響範囲を確認できる
- [ ] 自端末のIP設定を確認できる
- [ ] 同一ネットワーク内への疎通を確認できる
- [ ] デフォルトゲートウェイへの疎通を確認できる
- [ ] 別ネットワークへの疎通を確認できる
- [ ] IP指定と名前指定の結果を比較してDNS問題を切り分けられる
- [ ] DHCPによるアドレス取得を確認候補にできる
- [ ] サーバー側・サービス側の問題とネットワーク側の問題を分けて考えられる
- [ ] 確認結果から次に調べる場所を選べる
- [ ] 原因を決めつけず複数の可能性を残せる
- [ ] 確認済み・未確認・原因候補を整理して報告できる
- [ ] Linux側の確認とNetwork側の確認を組み合わせて切り分けられる
